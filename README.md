# Intel GPU Firmware — non-writing alpha channel

Install `intel.gpu.firmware.plg` through Unraid Plugins. Physical firmware writes are disabled; no setting enables them. Optional maintenance rehearsals require approval to stop affected workloads.

Source, scope and validation: https://github.com/centauri/unraid-intel-gpu-firmware/tree/main

Never place a developer candidate on this channel. Versioned source archives and checksums are attached to GitHub prereleases.
