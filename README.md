# Intel GPU Firmware — functional alpha channel

Install `intel.gpu.firmware.plg` through Unraid Plugins. Alpha 2 enables confirmed updates of compatible newer GSC firmware using official Intel IGSC. Review the selected GPU and affected workloads, prepare maintenance, check compatibility and explicitly confirm the exact GPU before writing. Installation and plugin updates never flash automatically.

The earlier alpha 1 was non-writing. This channel now delivers the functional updater. Only one ASRock A380 has historical physical update evidence; other configurations and interrupted-write recovery remain unvalidated. See the release notes for the pending live reboot-guard test.
