**Intel GPU Firmware — public alpha 2**

Discover Intel GPUs across board vendors, inspect firmware and install compatible newer GSC updates using official Intel IGSC.
Open Tools → System Information → Intel GPU Firmware. Installation, plugin updates, scans and reboot never flash automatically.
Every GSC update requires fresh compatibility checks, prepared GPU maintenance and confirmation of the exact GPU.
One ASRock A380 has historical physical update evidence. Other configurations and interrupted-write recovery remain unvalidated. See the included documentation for the workflow and limits.
