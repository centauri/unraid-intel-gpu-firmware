**Intel GPU Firmware — experimental preview 0.3**

Discover Intel GPUs across board vendors, inspect firmware and prepare checked GSC updates.
Open Tools → System Information → Intel GPU Firmware. Install, scans and reboot never flash firmware.
The default package blocks physical writes. The separate experimental candidate allows a GSC update only after fresh checks and exact confirmation.
No physical update or recovery has been validated. See the included documentation for build profiles, evidence and limits.
